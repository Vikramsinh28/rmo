## [1.0.0] - 2026-07-20

Initial open-source release of Kostra Boilerplate.

### Added

- Production-ready Next.js SaaS boilerplate with auth, billing, and file storage
- MIT License with attribution guidance
- `SECURITY.md`, `CONTRIBUTING.md`, and `CODE_OF_CONDUCT.md`
- GitHub issue and pull request templates
- Dependabot configuration for npm and GitHub Actions
- CI workflow for lint, build, and tests
